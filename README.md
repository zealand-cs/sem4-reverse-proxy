# Extensible Reverse Proxy

This program is a research project, for seeing how WASM compares to FFI in workloads
where the WASM/FFI modules will be called often.

It will look at implementation difficulty, performance and various other metrics,
all of which will be documented in the synopsis.

The entire synopsis exists in the `synopsis/` directory. It is written in Typst,
and can be rendered with that same tool.
